# Pollymon

Pollymon is an original browser monster-catching RPG prototype. It uses the familiar genre loop of overworld exploration, wild encounters, turn-based battles, captures, party growth, and a field guide, but all creatures, names, items, places, and art are custom to this project.

## Engine / Framework

Pollymon uses a lightweight HTML5 game stack:

- HTML for the app shell
- CSS for responsive layout and UI
- JavaScript with Canvas for the overworld renderer
- Inline SVG generated by game code for Pollymon creature art
- Node.js scripts for development, linting, formatting, tests, builds, and versioning

No third-party runtime packages are required.

## Requirements

- Node.js 20 or newer
- A modern browser

## Run

Start a local development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:4173
```

You can also open `src/index.html` directly in a browser for a quick file-based run.

## Build

Create a production build in `dist/`:

```bash
npm run build
```

The build script copies `src/` into `dist/` and writes `dist/build-info.json` with the package name, version, build time, and source folder.

## Quality Checks

Run linting:

```bash
npm run lint
```

Format files:

```bash
npm run format
```

Check formatting without changing files:

```bash
npm run format:check
```

Run tests:

```bash
npm test
```

## Versioning

The project version lives in `package.json` and follows semantic versioning.

Bump the patch version:

```bash
npm run version:bump
```

Bump a specific level:

```bash
npm run version:bump -- minor
npm run version:bump -- major
npm run version:bump -- 1.2.3
```

The version script updates `package.json` and adds an entry to `CHANGELOG.md`.

## Originality Note

Pollymon avoids Pokemon names, characters, assets, slogans, maps, and story material. "Pollymon" is its own monster-catching game concept.
