# Asset Attribution

Pollymon currently uses no third-party art, audio, fonts, sprites, tilesets, maps, or other game assets.

All visible game assets are generated with project code in `src/game.js` using Canvas drawing and inline SVG markup.

If third-party assets are added later, record each asset here with:

- Asset name
- Creator
- Source URL
- License
- Any required attribution text
- File path in this repository
