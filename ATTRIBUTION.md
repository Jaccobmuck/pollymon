# Asset Attribution

Pollymon currently uses no imported third-party art, audio, fonts, sprites, tilesets, maps, or other game assets.

All visible game assets are generated with project code in `src/game.js` using Canvas drawing and inline SVG markup. The files under `assets/` are project-made placeholders.

Candidate third-party asset sources and license notes are tracked in `docs/ASSET_WORKFLOW.md`. Do not import a candidate pack until the user has chosen it.

If third-party assets are added later, record each asset here with:

- Asset name
- Creator
- Source URL
- License
- Any required attribution text
- File path in this repository
